# 1.1.1

Retain rendered pages as you read, with accurate labels and progress. Background and PDF-tab protection remain available.

随阅读保留已绘制页面，界面文字与状态准确描述缓存保留功能；继续提供后台保护和 PDF 标签页常驻。

## Packages / 安装包

- `en-US.xpi`: English interface.
- `zh-CN.xpi`: 简体中文界面。
- Same features and plugin ID; install one language at a time. / 功能与插件 ID 相同，安装其中一种语言即可。
- Source ZIP and SHA-256 checksums included. / 附源码包和 SHA-256 校验。

Targets Zotero 10.0.6. The original implementations have user-reported working operation on macOS 27.0.1. Public localization builds are automatically checked; broader desktop testing is welcome.

See [README](https://github.com/Hanson-Wang-chn/zotero-keep-reader-ready#readme), [中文说明](https://github.com/Hanson-Wang-chn/zotero-keep-reader-ready/blob/main/README.zh-CN.md) and [CHANGELOG](https://github.com/Hanson-Wang-chn/zotero-keep-reader-ready/blob/main/CHANGELOG.md).

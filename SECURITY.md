# Security policy

Current maintenance focuses on the latest release. This plugin runs with Zotero plugin privileges and wraps internal reader methods; install release files from this repository and verify published checksums when appropriate.

Please do not post credentials, private PDFs, private library metadata, or exploitable security details in public issues. Contact the maintainer through the GitHub profile to arrange a private report. Ordinary compatibility/performance issues can use the public issue form.

The plugin does not upload document content or provide a remote service. GitHub-hosted update manifests and release downloads are handled by Zotero. Report any unexpected document-related network behavior.

# Original local distributions

Original byte-for-byte installers and source archives from before public bilingual packaging. Each directory includes SHA-256 hashes. Original 1.1.1 and 1.2.0 were user-reported working on macOS 27.0.1 / Zotero 10.0.6.

The original 1.0.0 lacks a required installation update URL; its historical release is marked accordingly. Use current language-specific GitHub Release packages for daily reading. See CHANGELOG.md for the reading-driven retention in 1.1.0 and clearer labels in 1.1.1.

Public v1.1.1 and v1.2.0 tags contain community-localized sources. These original files remain unchanged.
